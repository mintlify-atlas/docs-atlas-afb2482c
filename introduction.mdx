The [nodejs.org](https://nodejs.org) website is the primary online presence for the Node.js® JavaScript runtime. It is maintained by the [OpenJS Foundation](https://openjsf.org/) and an open community of contributors. This documentation covers contributing to, developing, and maintaining the website codebase.

<Note>
  This documentation is for contributors working on the **nodejs.org website codebase**. For Node.js API documentation, visit [nodejs.org/api](https://nodejs.org/api/).
</Note>

## What is this repository?

The `nodejs/nodejs.org` repository contains the full source code for the Node.js website. It is built using:

- **[Next.js](https://nextjs.org)** — React framework for static site generation and routing
- **[MDX](https://mdxjs.com/)** — Markdown with JSX for rich content pages
- **[Tailwind CSS](https://tailwindcss.com/)** — Utility-first CSS framework
- **[TypeScript](https://www.typescriptlang.org/)** — Type-safe JavaScript throughout
- **[next-intl](https://next-intl-docs.vercel.app/)** — Internationalization with 15+ languages

## Repository structure

The repository uses a **pnpm workspace** with two main areas:

| Path | Purpose |
|------|---------|
| `apps/site/` | Main Next.js website application |
| `packages/ui-components/` | Published `@node-core/ui-components` npm package |
| `packages/i18n/` | Translation configuration and locale files |
| `packages/rehype-shiki/` | Custom syntax highlighting plugin |
| `packages/remark-lint/` | Custom Markdown lint rules |

## Who maintains it?

The website is maintained by the **Node.js Website Team** — a group of collaborators with commit access. Contributions are accepted from anyone via pull requests.

- **Infrastructure**: Hosted on [Vercel](https://vercel.com) (sponsored) and [Cloudflare](https://cloudflare.com)
- **Translations**: Managed via [Crowdin](https://crowdin.com/project/nodejs-web)
- **Search**: Powered by [Orama](https://docs.oramasearch.com/)
- **Visual testing**: Automated via [Chromatic](https://www.chromatic.com/)
